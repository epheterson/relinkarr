# Security

relinkarr runs with write access to your media and download folders, and serves a small HTTP port, so security reports are taken seriously.

## Reporting a vulnerability

Report it privately through GitHub: **[Security > Report a vulnerability](https://github.com/epheterson/relinkarr/security/advisories/new)**. Please do not open a public issue, discussion or pull request for it.

Include what you found, how to reproduce it, and what an attacker could reach with it. You will get an answer as soon as I can, and credit in the advisory unless you would rather not.

## Supported versions

The latest release (the `latest` image). Fixes are not backported.
